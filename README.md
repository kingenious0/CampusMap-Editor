# CampusMap Editor

A lightweight offline indoor map editor for laying out rooms, corridors, entrances, facilities, and connections.

## Features
- Drag and drop object placement
- Select, move, rotate, and resize map items
- Pan and zoom the workspace
- Floor management and JSON import/export
- Local autosave
- No external dependencies

## Run locally
1. Open `CampusOS_Map_Editor_v7_FINAL_FIXED/index.html` in a browser.
2. Use the tools on the left to place items.
3. Use the toolbar to pan, zoom, rotate, or fit the map.

- `CampusOS_Map_Editor_v7_FINAL_FIXED/index.html` — main app UI
